# Ironhold brand assets

The Ironhold mark is the Gatehouse: an "H" for hold, drawn as two towers joined by an arched gate. The wordmark is custom lettering, so there's no font to install.

## Files

| File | Use |
|---|---|
| `ironhold-logo.svg` | Logo with the name, on light backgrounds |
| `ironhold-logo-on-dark.svg` | Logo with the name, on dark backgrounds |
| `ironhold-mark.svg` | Mark alone, on light backgrounds |
| `ironhold-mark-on-dark.svg` | Mark alone, on dark backgrounds |
| `ironhold-mark-small.svg` | Mark redrawn for 16 to 32 pixels, where the full mark's notches blur |
| `ironhold-avatar.svg` | Square icon: the mark on crimson, for avatars and app icons |
| `ironhold-social-preview.svg` | 1280 x 640 image for link previews |
| `favicon.ico` | Browser icon (16, 32 and 48 pixels) |
| `png/` | PNG versions: avatar (512), Apple touch icon (180), favicons (16, 32), social preview |

The SVG files are the source. The PNG files and `favicon.ico` are generated from them.

## Colors

| Name | Hex | Use |
|---|---|---|
| Crimson | `#D7263D` | The mark, links, primary buttons |
| Iron oxide | `#A8201A` | Hover and pressed states, print |
| Ink | `#15171C` | Text, dark backgrounds |
| Paper | `#F4F1EA` | Light backgrounds, text on dark backgrounds |

Crimson has a contrast ratio of 5.0:1 on white and 3.6:1 on Ink.

## Using the logo

- Leave clear space around the logo at least as wide as one tower of the mark.
- Below 32 pixels, use `ironhold-mark-small.svg`.
- Don't stretch, rotate or recolor the logo, add effects to it, or set the name in another font next to the mark.
